# 工厂建筑基础（Blender 插件）

建筑底面占格、物流端口与参数化碰撞代理的可视化编辑工具。目标测试版本为 **Blender 4.1.1**。

## 安装

1. 执行 `./build.ps1`，生成 `dist/factory_building-0.3.2.zip`。
2. Blender 4.1：`Edit > Preferences > Add-ons > Install…`，选择 ZIP。
3. 启用 **3D View: 工厂建筑基础**。
4. 在 3D 视图按 `N` 打开右侧栏，选择 **工厂建筑基础** 标签。

确认插件勾选成功；如果偏好设置未启用自动保存，请点击 **Save Preferences / 保存偏好设置**，以便下次启动自动启用。占格、端口数据需要使用 **保存 .blend** 保存，与插件启用偏好是两份不同的数据。

### 0.1.5 编辑快捷键

- 3D 视图的物体模式下，**Alt + S** 进入占格编辑，**Alt + F** 进入端口编辑。

- 启用插件时，物体模式下 Alt + S 使用插件绑定，替代 Blender 默认的清除缩放操作；网格编辑模式的原生快捷键不受影响。
- 禁用插件会移除两项快捷键，重新启用不会重复注册。

### 0.1.6 端口删除与右键菜单

- 鼠标位于端口列表时按 **Delete** 删除选中端口；端口编辑工具中也可直接按 Delete 删除。
- 列表中右键和端口编辑视口中右键显示“删除”“反转”两个操作；右键命中三角形时先选中该端口。
- 在 3D 视图及右侧栏中按 **Alt + D** 删除选中端口，两种编辑工具运行期间同样有效。
- 删除共用同一个支持撤销的操作，自动整理内部索引和产物槽位；列表 Delete 仅作用于本插件的端口列表。

## 大小和占用

- 默认 4 × 3 格，每格固定 1 Blender 单位，全部占用，不提供每格尺寸编辑。
- 栅格固定在世界原点的 **Z=0** 平面，包围矩形的底面中心位于原点。
- Blender X 对应游戏局部 X，Blender Y 对应游戏局部 Z。
- 浅绿色为占用，浅红色为空格；透明度可以调整。
- **渲染层级**默认“正常”，模型可以遮挡参考；切换为“总是在前”可以透过模型查看完整参考。
- 点击 **在视口中编辑占格** 或按 **Alt + S**：左键拖动涂占用，右键拖动清空；Enter 或 Esc 退出。
- 一次鼠标拖动作为一次修改。Esc 丢弃尚未松开鼠标的当前笔画，保留之前已完成的笔画。
- 中键旋转、Shift + 中键平移、滚轮缩放照常使用。操作期间的提示显示在视图顶部。
- 支持孔洞、凹边和不连通形状；全部清空可用于重画，但会提示至少保留一个占用格。
- 改变尺寸时按原有局部格坐标保留重叠区域，新增加的格子默认为占用；缩小会裁掉范围外数据。
- 参考绘制不创建任何 Mesh、Empty 或材质，不参与模型选择、编辑或渲染。关闭视口 Overlays 或“显示建筑参考”可隐藏。

## 端口位置

1. 点击 **添加 / 选择端口** 或按 **Alt + F**。
2. 将鼠标移到占格边界，最近的边段显示黄色，左键添加输入口；凹口和孔洞的边界同样有效。
3. 点击悬浮三角形可以选中对应端口；点击已有端口所在的边界同样会选中，不会叠加新端口。
4. 选中后按 **R** 切换输入/输出，连接格和物理边界保持不变，物流方向自动反转，并分配新类型下的内部索引；切成输出时自动分配产物槽位。
5. 按 Enter 或 Esc 退出工具。面板中也可以切换类型（同样会反向），修改坐标、方向和输出产物槽位，或删除端口。

蓝色箭头为输入，橙色为输出；箭头悬浮于边界上方，始终指向物品运动方向。白色轮廓表示列表中的当前端口。无效端口显示红色，并在面板中给出原因。

端口沿用主项目规则：

- `cell_x/cell_z` 是未旋转的 **建筑外侧连接格**，不是建筑内部格子。允许包围矩形外、凹口与孔洞中的空格。
- 输入：连接格加方向必须落在占用格上；输出：连接格减方向必须落在占用格上。
- 内部索引从 0 开始，输入与输出分别按当前列表顺序连续编号，不显示或开放编辑。删除或反转端口后自动重排，不留下空缺。
- 输入口不显示编号；输出口只显示从 1 开始的产物槽位，不再提供单独的出口编号。删除一个输出后，后续槽位前移；新增输出使用现有输出数 + 1。手动调整槽位时，与目标槽位交换；超出当前输出数量的值会被限制在有效范围。
- 修改占格或尺寸不会自动删除已有端口；不再合法的端口会被标红，供人工调整。

例如 `4 × 3`、位图 `1111/1111/1100`：凹边建筑格 `(2,1)` 的 +Y 边可添加连接格 `(2,2)` 的输入口，物流方向为 Blender -Y / 游戏 -Z。

## 保存与范围

配置保存在当前 Scene 的属性中，随 `.blend` 保存；每个 Scene 对应一份建筑配置。使用 Ctrl+Z / Ctrl+Shift+Z 撤销与重做。模型建议以底面包围矩形中心为原点；工具不会自动移动模型。

本版本实现占格、端口、碰撞代理制作与 `.factory.json` 导出，不包含 FBX 导出或 Unity 导入器。

## 导出 .factory.json

1. 保存 `.blend` 工程，以确定导出名称和目录。
2. 完成占格、端口和碰撞代理编辑，结束编辑工具并切换到物体模式。
3. 在右侧 **工厂建筑基础 > 导出** 点击 **导出 .factory.json**；或使用 **文件 > 导出 > 工厂建筑数据（.factory.json）**。
4. 在弹出的文件窗口中选择目录和文件名，默认与工程同名、同目录。右侧勾选 **导出占格 / 导出端口 / 导出碰撞代理**，默认全部勾选，至少选择一项。
5. 确认导出。使用当前 Scene 的最新内存配置，不会自动保存 `.blend`。

未勾选的内容从 JSON 中省略，Unity 导入时应保留对应已有数据；勾选后导出的空数组表示更新为空。
部分导出会完整替换目标 JSON，不合并旧文件。只校验本次导出的内容；端口位置校验仍依赖占格边界。

包含占格长宽/位图、连接格与方向、自动维护的端口索引和产物槽，以及代理类型、位置、旋转和尺寸。
隐藏代理仍会导出，其他 Scene 的代理不会混入。非法端口、空占格、非单位缩放、剪切、镜像或非有限参数会阻止导出，并保留上次成功文件。

数据已按 `(Blender X, Y, Z) → (Unity X, Z, Y)` 转换，旋转为基变换后的 Unity 四元数。
完整约定、Unity 源表字段对应及导入端职责见 [Factory JSON 格式说明](docs/factory-json-format.md)，
另附 [JSON Schema](docs/factory-json.schema.json) 和 [完整示例](examples/测试建筑.Model.factory.json)。
FBX 需要单独导出并匹配相同原点、朝向和单位；同名模型文件名记录在 JSON 的 `building.model_file` 中。

## 碰撞代理

### 创建与编辑

1. 在物体模式下，使用 **添加（Shift + A）> 工厂碰撞代理**，选择盒体、球体、圆柱体或胶囊体。右侧栏“工厂建筑基础 > 碰撞代理”也提供四个创建按钮。
2. 代理的中心创建在 **3D 游标** 位置，并自动放入当前 Scene 的“工厂碰撞代理”集合。若要使底面落在 Z=0，将中心高度设置为形状总高度的一半。
3. 点击代理外形或在 Outliner 中选中它。右侧面板显示对应的形状参数：

| 形状 | 可编辑参数 |
|---|---|
| 盒体 | 局部 X / Y / Z 的长、宽、高 |
| 球体 | 半径 |
| 圆柱体 | 半径、总高度，局部 Z 为轴线 |
| 胶囊体 | 半径、包含两端半球的总高度，局部 Z 为轴线 |

胶囊体总高度必须至少为直径。增大半径或减小高度时会自动维持该约束；总高度等于直径时外形为球体。尺寸单位与占格相同，均为 Blender 原始单位。

### 原生操作与选择

- **G** 移动、**R** 旋转、**Shift + D** 复制、**Delete** 删除；支持原生撤销与重做。
- 普通点击选择一个代理，Shift + 点击切换多选。没有命中代理时继续使用 Blender 原生选择，不影响模型选择。
- 代理是 Empty，没有 Mesh 数据，不能通过 Tab 编辑顶点；尺寸在形状参数面板中调整，对象缩放通道默认锁定。
- 复制后的形状参数彼此独立，不会联动修改原代理。
- 绘制与点选遵循“大小和占用”面板中的渲染层级：正常模式下，模型能遮挡代理；总是在前模式下，可以透过模型查看和选择代理。
- “显示碰撞代理”控制插件绘制；关闭视口 Overlays 同样隐藏代理绘制。代理不参与最终图像渲染。

类型由对象的 `factory_collider` 属性识别，另有 `factory_role=collider` 标记。名称默认以 `UnityCollider_` 开头，可以自由改名。

缩放锁定用于常规交互；如果通过脚本、父级或约束绕过锁定，面板会提示缩放错误并将代理标红。插件始终根据世界位置、旋转及形状参数绘制合法形状，不把缩放解释为椭球或其他变形。应将代理自身和父级缩放恢复为 1，否则 JSON 导出会拒绝。Unity Collider / Prefab 由后续 Unity 导入器生成。

### 从所选模型拟合

编辑模式也支持按局部选区创建：选择顶点、边或面后，右键 **生成外接几何碰撞代理（选中部分）**，选择立方体、球、圆柱体或胶囊体；右侧“碰撞代理”面板提供同样入口，也可通过 F3 搜索“为选中几何生成外接碰撞代理”。

每次操作为当前选区生成一个独立代理，放入“工厂碰撞代理”集合，保持编辑模式及原选区，可连续选择模型的其他部分生成多个代理。多物体编辑时合并所有正在编辑物体的选区，使用活动物体的局部轴向；缩放计入尺寸。仅拟合可见的选中编辑网格，不包含修改器效果；面、线、点等退化尺寸使用最小厚度。创建后切回物体模式选择代理调整参数，支持撤销/重做。

在 **物体模式** 下选择含几何数据的普通物体，右键：

```text
单选：生成外接几何碰撞代理
      ├─ 立方体
      ├─ 球
      ├─ 圆柱体
      └─ 胶囊体

多选：生成外接几何碰撞代理（每个）→ 四种形状
      生成外接几何碰撞代理（整体）→ 四种形状
```

- **单个 / 每个**：按每个物体各自的局部轴拟合，生成的代理保留对应世界朝向。模型整体旋转不会使尺寸像世界轴对齐包围盒那样膨胀；对象缩放及父级变换计入包围尺寸。
- **整体**：生成一个包住全部所选几何的代理，以 **当前活动物体** 的局部轴作为整体轴向；没有有效活动物体时取所选中的第一个。
- 盒体按三个轴的范围生成；球按中心到最远顶点的距离生成；圆柱体沿局部 Z 轴计算高度和径向范围；胶囊体沿局部 Z 轴，同时校验两端半球对所有顶点的包围。
- 中心使用拟合坐标系内包围范围的中点，提供确定性的保守包围，不是最小体积优化求解。
- 原模型及其网格、修改器、变换保持不变；代理生成后独立，后续不会跟随模型更新。生成的代理自动选中，可继续调整参数；一次生成支持撤销。
- 所选对象需均为可转换为网格的普通几何对象；碰撞代理、相机、灯光和普通 Empty 不参与此入口。空网格或无法取得几何数据时取消整批生成，不留下半批结果。

`tests/blender_colliders.py` 在后台验证四类代理的创建、参数约束、轮廓尺寸、解析射线求交、复制隔离和 `.blend` 保存重开：

```powershell
& 'D:/Application/Blender 4.1/blender.exe' --background --factory-startup --python-exit-code 1 --python tests/blender_colliders.py
```

`tests/blender_collider_viewport.py` 使用真实视口事件验证创建菜单、形状表面点选、原生 G/R/Shift+D/Delete、禁止网格编辑、缩放锁定、模型选择回退、遮挡点选和 GPU 绘制；运行参数与 `blender_viewport.py` 相同。截图与结果保存在 `test-results/`，命令行重定向日志请放入 `log/`。

`tests/blender_collider_fit.py` 后台验证四种形状对求值顶点的包围、局部坐标、世界旋转不变性、偏移原点、修改器、负缩放、父级剪切、多选每个/整体、菜单结构及失败整批取消。

`tests/blender_collider_fit_viewport.py` 验证真实单选/多选右键菜单、拟合操作、撤销重做及整体胶囊体；运行参数与其他非后台视口测试相同。

`tests/blender_export.py` 后台验证完整 JSON、同名/中文路径、四元数基变换、父级姿态、非法数据拒绝、原子替换失败保护、隐藏代理、Scene 隔离和确定性导出。
`tests/blender_export_viewport.py` 验证真实 File Export 菜单、未保存时禁用、编辑工具运行时拒绝导出和覆盖最新参数。
