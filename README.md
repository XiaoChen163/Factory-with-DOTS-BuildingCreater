# 工厂建筑基础（Blender 插件）

建筑底面占格与物流端口的可视化编辑工具。目标测试版本为 **Blender 4.1.1**。

## 安装

1. 执行 `./build.ps1`，生成 `dist/factory_building-0.1.7.zip`。
2. Blender 4.1：`Edit > Preferences > Add-ons > Install…`，选择 ZIP。
3. 启用 **3D View: 工厂建筑基础**。
4. 在 3D 视图按 `N` 打开右侧栏，选择 **工厂建筑基础** 标签。

确认插件勾选成功；如果偏好设置未启用自动保存，请点击 **Save Preferences / 保存偏好设置**，以便下次启动自动启用。占格、端口数据需要使用 **保存 .blend** 保存，与插件启用偏好是两份不同的数据。

- 移除“工厂建筑基础”父面板，大小和占用、端口位置为右侧栏内的两个同级折叠面板。
- 点击边界添加输入口，点击悬浮三角形选中端口，R 切换输入/输出并反向物流方向。
- 内部索引按输入/输出类型分别自动递增，不显示或开放编辑；输入不显示编号，输出只显示产物槽位。

### 0.1.3 中键导航修复

- 修复原生视口旋转/平移接管中键释放事件后，插件错误地一直停留在导航等待状态的问题。
- 两种编辑工具都能在中键旋转、Shift + 中键平移后立即继续编辑，无需退出重进。
- 中途开始导航会提交已有占格笔画并清理悬停状态，避免导航结束后误连笔。

### 0.1.4 固定格尺寸与连续索引

- 每格固定为 1 Blender 单位，不提供尺寸修改；旧文件的格尺寸设置不再生效。
- 输入/输出内部索引分别从 0 连续排列，产物槽从 1 连续排列，删除或反转后自动收紧空缺，不保留累计计数器。
- 旧文件中的累计索引和槽位空缺会自动整理；调整已有输出槽位时与目标槽位交换，保持绑定唯一且连续。

### 0.1.5 编辑快捷键

- 3D 视图的物体模式下，**Alt + S** 进入占格编辑，**Alt + F** 进入端口编辑。
- 编辑过程中也可用这两个快捷键直接切换工具，当前占格笔画会先提交；Enter / Esc 退出。
- 启用插件时，物体模式下 Alt + S 使用插件绑定，替代 Blender 默认的清除缩放操作；网格编辑模式的原生快捷键不受影响。
- 禁用插件会移除两项快捷键，重新启用不会重复注册。

### 0.1.6 端口删除与右键菜单

- 鼠标位于端口列表时按 **Delete** 删除选中端口；端口编辑工具中也可直接按 Delete 删除。
- 列表中右键和端口编辑视口中右键显示“删除”“反转”两个操作；右键命中三角形时先选中该端口。
- 在 3D 视图及右侧栏中按 **Alt + D** 删除选中端口，两种编辑工具运行期间同样有效。
- 删除共用同一个支持撤销的操作，自动整理内部索引和产物槽位；列表 Delete 仅作用于本插件的端口列表。

### 0.1.7 建筑参考渲染层级

- “大小和占用”面板新增 **渲染层级**：**正常**（默认）遵循场景深度，参考会被物体遮挡；**总是在前**不受其他物体遮挡。
- 栅格、端口箭头、选中/悬停轮廓及端口文字统一遵循此选项；半透明参考不写入场景深度。
- 选项随 `.blend` 保存；旧文件未配置此选项时默认使用正常。

源码也可以直接复制为 Blender 插件目录下的 `factory_building` 文件夹。

## 大小和占用

- 默认 4 × 3 格，每格固定 1 Blender 单位，全部占用，不提供每格尺寸编辑。
- 栅格固定在世界原点的 **Z=0** 平面，包围矩形的底面中心位于原点。
- Blender X 对应游戏局部 X，Blender Y 对应游戏局部 Z。
- 浅绿色为占用，浅红色为空格；透明度可以调整。
- **渲染层级**默认“正常”，模型可以遮挡参考；切换为“总是在前”可以透过模型查看完整参考。
- 点击 **在视口中编辑占格** 或按 **Alt + S**：左键拖动涂占用，右键拖动清空；Enter 或 Esc 退出。
- 一次鼠标拖动作为一次修改。Esc 丢弃尚未松开鼠标的当前笔画，保留之前已完成的笔画。
- 中键旋转、Shift + 中键平移、滚轮缩放照常使用。操作期间的提示显示在视图顶部。
- 支持孔洞、凹边和不连通形状；全部清空可用于重画，但会提示至少保留一个占用格。
- 改变尺寸时按原有局部格坐标保留重叠区域，新增加的格子默认为占用；缩小会裁掉范围外数据。
- 参考绘制不创建任何 Mesh、Empty 或材质，不参与模型选择、编辑或渲染。关闭视口 Overlays 或“显示建筑参考”可隐藏。

## 端口位置

1. 点击 **添加 / 选择端口** 或按 **Alt + F**。
2. 将鼠标移到占格边界，最近的边段显示黄色，左键添加输入口；凹口和孔洞的边界同样有效。
3. 点击悬浮三角形可以选中对应端口；点击已有端口所在的边界同样会选中，不会叠加新端口。
4. 选中后按 **R** 切换输入/输出，连接格和物理边界保持不变，物流方向自动反转，并分配新类型下的内部索引；切成输出时自动分配产物槽位。
5. 按 Enter 或 Esc 退出工具。面板中也可以切换类型（同样会反向），修改坐标、方向和输出产物槽位，或删除端口。

蓝色箭头为输入，橙色为输出；箭头悬浮于边界上方，始终指向物品运动方向。白色轮廓表示列表中的当前端口。无效端口显示红色，并在面板中给出原因。

端口沿用主项目规则：

- `cell_x/cell_z` 是未旋转的 **建筑外侧连接格**，不是建筑内部格子。允许包围矩形外、凹口与孔洞中的空格。
- 输入：连接格加方向必须落在占用格上；输出：连接格减方向必须落在占用格上。
- 内部索引从 0 开始，输入与输出分别按当前列表顺序连续编号，不显示或开放编辑。删除或反转端口后自动重排，不留下空缺。
- 输入口不显示编号；输出口只显示从 1 开始的产物槽位，不再提供单独的出口编号。删除一个输出后，后续槽位前移；新增输出使用现有输出数 + 1。手动调整槽位时，与目标槽位交换；超出当前输出数量的值会被限制在有效范围。
- 修改占格或尺寸不会自动删除已有端口；不再合法的端口会被标红，供人工调整。

例如 `4 × 3`、位图 `1111/1111/1100`：凹边建筑格 `(2,1)` 的 +Y 边可添加连接格 `(2,2)` 的输入口，物流方向为 Blender -Y / 游戏 -Z。

## 保存与范围

配置保存在当前 Scene 的属性中，随 `.blend` 保存；每个 Scene 对应一份建筑配置。使用 Ctrl+Z / Ctrl+Shift+Z 撤销与重做。模型建议以底面包围矩形中心为原点；工具不会自动移动模型。

本版本实现占格与端口编辑，不包含碰撞代理、FBX/JSON 导出或 Unity 导入。

## 验证

```powershell
& 'D:/Application/Blender 4.1/blender.exe' --background --factory-startup --python-exit-code 1 --python tests/blender_smoke.py
```

`tests/blender_viewport.py` 必须在单独的 **非后台** Blender 4.1 测试进程中运行；它会执行交互与 GPU 测试、生成截图，然后关闭该测试进程。不要在正在工作的 Blender 中执行此脚本。

```powershell
& 'D:/Application/Blender 4.1/blender.exe' --factory-startup --enable-event-simulate --python tests/blender_viewport.py
```

输出位于 `test-results/`。测试覆盖尺寸变化、异形占格与端口校验、保存重开、插件重新注册、从侧栏启动交互工具、连续涂选、取消笔画、边界点选、撤销重做和 GPU 视口绘制。

真实安装与跨进程加载回归（Windows / Blender 4.1）：

```powershell
& 'D:/Application/Blender 4.1/4.1/python/bin/python.exe' tests/addon_lifecycle.py 'D:/Application/Blender 4.1/blender.exe' dist/factory_building-0.1.7.zip
```

该测试会建立临时便携运行目录和独立配置，写偏好前必须确认配置路径位于临时目录。仅设置 `BLENDER_USER_CONFIG` 不足以隔离已有便携版的 `4.1/config`。

`tests/blender_navigation.py` 使用真实窗口事件，验证两种编辑工具在原生中键旋转和 Shift + 中键平移后继续编辑；运行参数与 `blender_viewport.py` 相同。

`tests/blender_shortcuts.py` 使用真实窗口按键验证 Alt + S / Alt + F 进入和切换工具、默认清除缩放操作不会误触发，以及快捷键启停清理；运行参数与 `blender_viewport.py` 相同。

`tests/blender_port_actions.py` 验证端口列表 Delete、列表和视口右键菜单、侧栏和视口 Alt + D、编辑中的删除，以及删除后的产物槽连续性。

`tests/blender_render_layers.py` 在真实 GPU 上检查栅格、端口箭头与文字的像素遮挡，确认两种渲染层级和 GPU 状态恢复；运行参数与 `blender_viewport.py` 相同。
